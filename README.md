# Šarlote Bērziņa — Kusties apzināti

Vienas lapas, responsīva fizioterapijas iedvesmotu treniņu mājaslapa latviešu valodā.

## Palaišana lokāli
Atver `index.html` pārlūkā. Nav nepieciešama būvēšana vai npm instalācija.

## Publicēšana Vercel
1. Augšupielādē šīs mapes failus GitHub repozitorijā.
2. Vercel izvēlies **Add New → Project** un importē repozitoriju.
3. Framework Preset: **Other**; Build Command atstāj tukšu; Output Directory: `.`.
4. Spied **Deploy**.
